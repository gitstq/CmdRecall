# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-05-12

### Added
- 🎉 Initial release
- 🔍 Intelligent command search with TF-IDF and BM25 algorithms
- 📊 Command ranking by frequency, recency, and relevance
- 🏷️ Automatic command classification (Git, Docker, K8s, etc.)
- ⚠️ Risk level assessment for dangerous commands
- 📝 Command template management with variable substitution
- 🖥️ Beautiful TUI interface (optional)
- 🐚 Multi-shell support (Bash, Zsh, Fish)
- 💾 SQLite-based storage with zero configuration
- 🔄 History sync functionality
- 📈 Statistics and analytics

### Features
- Zero dependencies (core functionality)
- Cross-platform (Linux, macOS, Windows)
- Fast and lightweight
- Easy to use CLI interface
- Extensible architecture
